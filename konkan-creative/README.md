# Konkan Creative

Second site: the graphic design and animation studio of Fuzail Khan, aimed at
restaurants, cafés and local businesses in Goa. Plain static HTML/CSS/JS, no build.

- `index.html`: all page content
- `assets/style.css`: palette tokens at the top (cream paper, ink, laterite red, turmeric, sea teal)
- `assets/main.js`: set `WHATSAPP` to your number (country code, no + or spaces) to turn every
  chat button into a WhatsApp link; while empty they fall back to email
- `assets/img/`: photo and link-preview image

Deployed as its own Vercel project with Root Directory `konkan-creative`.
